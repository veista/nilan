# CTS400 (dump-gated)

The Nilan App gateway documentation lists **CTS400** for some Comfort residential software versions, alongside CTS602 / CTS602i / CTS602Light.

## Status on this fork

**Not implemented.** There is no CTS400 board constant, device module, or register class until a verified Modbus map and live dump exist.

## What to send

- Confirmation the unit is CTS400 (plate / HMI)
- Connection type (RJ45 Modbus as in gateway docs)
- Unit id and baud settings if configurable
- Holding/input register list from Nilan PDF or your reads
- Which values you need in Home Assistant

Checklist: [CONTRIBUTING.md](../../CONTRIBUTING.md#register-dump-checklist).

## Meanwhile

If the unit is actually CTS602 commercial (Comfort 600+, VPM, VPR), use board **CTS602** and Auto-detect. See [README.md](README.md).
