# VP18 M2 (CTS602)

| Item | Value |
|---|---|
| Controller | CTS602 |
| HMI / plate | VP18 M2 F (and similar M2 labelling) |
| Control type id | 32 |
| Typical unit id | 30 |
| Config board choice | CTS602 or Auto-detect |

## Hardware

Use a Modbus RTU↔TCP bridge or USB-RS485. See [hardware](../hardware.md).

## Setup in Home Assistant

1. Install the integration ([installation](../installation.md)).
2. Add **Nilan** → **TCP** or **Serial**.
3. Prefer **Auto-detect**, or select board **CTS602**.
4. Set unit id (default **30** unless your unit differs).
5. Confirm the device model in HA matches **VP18 M2** (type id 32).

## Expected behaviour

Basic air and water temperatures and related CTS602 entities should load when bus version and options allow. Full parity with every VP18 variant is still community-validated; please share a register dump if something is missing ([CONTRIBUTING.md](../../CONTRIBUTING.md)).

Tracking: [veista/nilan#232](https://github.com/veista/nilan/issues/232).

## Troubleshooting

- Unsupported device: enable debug logging; confirm type id **32** appears in the log.
- See [CTS602 overview](README.md) and [FAQ](../faq.md).
