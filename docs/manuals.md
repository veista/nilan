# Manufacturer manuals (official downloads)

This repository does **not** host Nilan PDF manuals. Those documents are copyrighted by Nilan A/S. Use the official download portals instead.

## Where to download

| Source | URL | Notes |
|--------|-----|--------|
| Nilan Norway downloads / archive | https://www.nilan.no/last-ned/arkiv | Discontinued and historical unit docs |
| Nilan Norway product pages | https://www.nilan.no/ | Current SKUs: open product → **Last ned** |
| Nilan Denmark (EN) | https://www.en.nilan.dk/ | English installation / software PDFs under Downloads |

Search the archive or product page by **model name** (for example Compact P, Compact P Nordic, Comfort CT200) and document type (brukerveiledning / montasjeveiledning / software).

## CTS700 Compact P (common for this integration)

Useful document types when mapping Modbus or wiring:

- **Montasjeveiledning** (installation): sensor labels T1–T12, duct connections, electrical
- **Brukerveiledning** (user): CTS panel menus, DHW / VV settings, week programs
- **Software / Modbus** notes when published for the board era (2015 map, 2018 protocol, Nordic LC)

Product hub (NO): [Compact P Nordic](https://www.nilan.no/produkter/ventilasjon-med-oppvarming/ventilasjon-og-varmtvann/compact-p-nordic)
