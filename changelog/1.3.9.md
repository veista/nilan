# 1.3.9 (10/08/2026)

**Title:** Nordic room/DHW setpoint writes via FC6

**Tag:** [v1.3.9](https://github.com/master3395/veista-nilan/releases/tag/v1.3.9)  
**Author:** master3395

## What changed

- Room setpoint (**4746**) and DHW setpoint (**20460**) now write with Modbus **FC6** (`write_register`) first, matching Home Assistant YAML climate defaults
- Fall back to FC16 if needed; success is decided by temperature readback
- Fan step writes still work (FC6 then FC16); Modbus timeout raised to 3s
- Climate and water heater UI update optimistically and refresh on rejected writes

## Operator notes

- Restart Home Assistant / reload Nilan after upgrade
- If a setpoint still snaps back, check logs for `CTS700 Nordic temp write` and whether a week program is overwriting HA

## Scope

`device_cts700_nordic.py`, `climate.py`, `water_heater.py`, Nordic docs.
