# 1.3.16 (04/10/2026)

**Title:** CTS700 Compact P electrical supplement heater switch (20464)

**Author:** master3395  
**GitHub Release (notes only):** [v1.3.16](https://github.com/master3395/veista-nilan/releases/tag/v1.3.16)

Upgrade via **HACS** (or git pull), then reload the Nilan config entry.

## What changed

- CTS700 Compact P **2018+**: holding **20464** (electrical supplement heater, 0/1) is a writable Home Assistant **switch**, not read-only status
- Water heater entities still use the same getter for DHW running state
- CTS700 Nordic hybrid: still no dedicated el-supplement register; writes to 20464 are refused. CTS602 unchanged (output **116** status)

## Operator notes

- Default entity id when the device is named `Nilan`: `switch.nilan_electrical_supplement_heater`
- This switch enables DHW electrical supplement. It is not a command to heat the tank bottom to 60 C. Heat pump DHW still around **55 C** at T12. Scalding protection is **20463**.
- Do not enable this switch on a Nordic XL config entry; that board path does not expose 20464.

## Scope

`device_cts700.py`, `device_map_cts700.py`, `switch.py`, `device_cts700_nordic.py`, translations, `manifest.json`, CTS700 docs.
