# 1.3.13 (16/08/2026)

**Title:** Setup-time register probe, auto-disable of dead-register entities, Nordic inlet/exhaust filter days

**Tag:** [v1.3.13](https://github.com/master3395/veista-nilan/releases/tag/v1.3.13)  
**Author:** Martsola

## What changed

- New setup-time register probe: registers the unit does not implement are detected once when a device is added and their entities are created disabled by default (WARNING logged once per dead register at setup, no recurring ERROR spam)
- Probe results are persisted in the config entry — HA restarts/reloads load stored results silently (no WARNING burst, no modbus hub error lines)
- CTS700 Nordic filter entities: inlet/exhaust interval diagnostics (1326/1327), days-to (1328/1329 remaining), days-since (interval − remaining) — values match the HMI
- No register definitions removed — dead registers stop being polled only on units that lack them; units that have them probe alive and poll normally (variant-safe)
- Replaced deprecated `CONCENTRATION_PARTS_PER_MILLION` with `UnitOfRatio.PARTS_PER_MILLION`

## Operator notes

- Existing config entries keep working (backwards compatible).
- **Remove and re-add each Nilan config entry once** after upgrading so the probe runs and its result is stored. After that, restarts are silent.
- Entities disabled by the probe can be re-enabled manually in HA if a register was wrongly judged dead.
- If you change unit firmware or wiring, remove and re-add the entry to re-scan.

## Scope

`register_probe.py` (new), device classes (CTS602, CTS700, CTS700 legacy, CTS700 Nordic), `__init__.py` persistence, sensor/binary_sensor entity gating, Nordic inlet/exhaust filter entities, `registers.py` (additions only), translations.
