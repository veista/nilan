# 1.3.7 (09/08/2026)

**Title:** Nordic XL UX fixes from mark007 feedback

**Tag:** [v1.3.7](https://github.com/master3395/veista-nilan/releases/tag/v1.3.7)  
**Author:** master3395

## What changed

- Climate fan modes on **CTS700_NORDIC** are **1–4** only (no unused fan 0)
- HVAC mode set refreshes from holding **5432** readback; turn-on no longer forces dehum/auto before heat/cool; warns if firmware reverts the write
- Nordic water heaters: no unreliable **Off** operation (temperature control only; shared DHW setpoint **20460**)
- Sensor labels follow Nilan wiring names (T1 outdoor, T6 evaporator, T7 after after-heater, T8 preheater path)
- T6/T7/T9 marked diagnostic; T7 disabled by default and hidden when bus reads ~0 C (missing sensor)

## Operator notes

- Restart Home Assistant after upgrade; reload the Nilan integration if entities were already created
- If HVAC mode stays on Cool after changing mode, the controller may treat 5432 as status; check logs for `CTS700 Nordic HVAC mode write`
- Existing T7 entity may need a UI enable toggle if you add an after-heater later

## Scope

`device_cts700_nordic.py`, `climate.py`, `water_heater.py`, `sensor.py`, translations, Nordic docs.
