## What changed

- CTS700 Nordic exposes **bypass status** from holdings **4704** / **21773** (binary flap + percent sensor). Still **read-only**; Ethernet bypass writes remain unreliable
- Documented Ethernet / YAML dual-path limits for Core **2026.11.0** / HAOS **18.5.rc1** (Supervisor 2026.11.0, Frontend 20261028.4)
- CTS700 AI packages: runtime context (date / HA version), write-busy watchdog, clearer system prompt (no street addresses)
- Nordic example dashboard entity ids and dual-path migration notes updated so Lovelace does not depend on disabled YAML Modbus entities

## Operator notes

- After upgrade, enable new bypass entities if they appear disabled by the register probe
- Keep YAML Modbus for the same unit paused; remap templates to Nordic `binary_sensor.*bypass*` / `sensor.*bypass_damper_percent*` instead of YAML `switch.bypass_damper`
- DHW dial vs tank: use water heater current temperature, not the Ethernet dial cap
- If AI autotune looks idle, check `input_boolean.nilan_cts_write_busy` (watchdog clears after 10 minutes when the helper exists)
