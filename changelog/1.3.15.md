# 1.3.15 (03/09/2026)

**Title:** Filter alarm logging + binary/switch last-good Modbus reads

**Author:** master3395  
**GitHub Release (notes only):** [v1.3.15](https://github.com/master3395/veista-nilan/releases/tag/v1.3.15)

Upgrade via **HACS** (or git pull), then reload the Nilan config entry.

## What changed

- Binary sensors and switches keep the last good on/off value when a Modbus read returns `None` (same pattern as sensors/numbers in 1.3.14). Stops Filter Alarm and similar entities flickering to `unknown`
- CTS700 Nordic **Filter Alarm** (input 5168): `WARNING` when a read fails; `INFO` when the alarm toggles ON/OFF; `DEBUG` while it stays ON
- Enables operators to correlate Filter Alarm glitches with Ethernet load / dual Modbus hubs in Home Assistant logs

## Operator notes

- Set logger `custom_components.nilan.device_cts700_nordic: debug` (or `info`) to see filter-alarm transitions.
- Prefer a single Modbus TCP client to the unit when possible (integration **or** YAML hub).

## Scope

`binary_sensor.py`, `switch.py`, `device_cts700_nordic.py`, `manifest.json`.
