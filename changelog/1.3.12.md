# 1.3.12 (14/08/2026)

**Title:** VP 18comp (hw_type 11) entity mapping from upstream #234

**Tag:** [v1.3.12](https://github.com/master3395/veista-nilan/releases/tag/v1.3.12)  
**Author:** master3395

## What changed

- Port [veista/nilan#234](https://github.com/veista/nilan/pull/234) (DUC750): add hw_type **11** (`VP 18comp`) to entity `supported_devices` where registers were live-verified, including the missing **compressor DHW setpoint** that blocked both water heater entities.
- Replace unreachable `(None,)` with `(11,)` for T2 / T9 / T16 / room master / after-heat capacity / supply after heating (left `get_hps_water_heater_setpoint` and `set_display_button` as `(None,)` per upstream).
- German T5 label: **Kondensatortemperatur** (condenser), not Kondensattemperatur (condensate).

## Operator notes

- Reload Nilan / restart HA after upgrade. VP 18comp users should see water heaters and additional sensors (bypass flap, etc.). Disable unused optional entities in the UI if hardware is not fitted.
- Thanks to [DUC750](https://github.com/DUC750) for the measured register dump and upstream PR.
