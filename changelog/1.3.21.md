## What changed

- **HVAC heating accuracy:** `hvac_action=heating` only when a heat source is actually running (holding **4706** compressor effort > 0 and/or heater bit **4701**). Mode=heat alone no longer paints a continuous heating band during thermostat **hysteresis** (smart-plug idle ~40 W vs heat ~500-700 W; thanks [@mark007](https://github.com/mark007))
- Main compressor effort % + heat-pump binary from **4706** (carried from 1.3.20 work)
- Electrical supplement switch **20464** (live R/W restore OK) + numbers **20463** scalding / **20462** el-supplement below
- Ventilation pause **20100**, DHW production pause **20440** + days **20441**
- Fan step display when **4747** holds percent (e.g. 80): map via **21771** / nearest of **20140/42/44/46**
- Cooling enable **20180** + humidity strategy **20160**–**20163**
- Polar frost/preheat **20300**, **20340**, **20341** + anti-legionella **20480**–**20483**
- Docs, Nordic YAML sample, Nordic XL dashboard, EN/NB/DE/FI/IT strings

## Operator notes
