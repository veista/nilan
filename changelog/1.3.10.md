## What changed

- Private Modbus hub names are always `nilan_hub_<entry_id>` so they never collide with a YAML hub named `nilan` (blank board/confirm menus)
- Config flow menus: clearer board labels, confirm as Accept / Manual menu, coexistence warnings on every setup step
- Device Firmware / software field no longer includes live outdoor temperature (map label only)
- FAQ and installation: YAML + Nilan must not share one unit; rename hubs away from bare `nilan`
- Nordic **T8**: if input **5159** mirrors **T1**, try holding **20296**; document equal T1/T8 as normal with idle preheater; T8 marked diagnostic

## Operator notes

- Existing config entries keep working (backwards compatible). Reload Nilan after upgrade so hubs rename.
- If menus were blank: rename YAML hub `nilan` → e.g. `nilan_compactpc`, restart HA, retry setup
