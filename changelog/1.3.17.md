# 1.3.17 (04/11/2026)

**Title:** Fix blank Add Hub board menu labels (#6)

**Author:** master3395  
**GitHub Release:** [v1.3.17](https://github.com/master3395/veista-nilan/releases/tag/v1.3.17)

Upgrade via **HACS** (or git pull), then reload the Nilan integration / restart Home Assistant.

## What changed

- Config-flow menus (interface, board, confirm) pass **explicit option labels** so the five board choices never render as empty rows (issue #6)
- Added Danish (`da`) config-flow translations for Add Hub setup
- Board step descriptions clarify Compact P GEO / NCS-700 vs Nordic XL vs 2018+ Compact P
- Filled board menu strings for German, Italian, and Finnish translations

## Operator notes

- If a YAML Modbus hub is still named bare `nilan`, rename it (for example `nilan_compactpc`) and reload Modbus. Labels should already be visible in 1.3.17; renaming still helps other strings and coexistence.
- Compact P GEO on NCS-700: start with **Auto-detect**, or pick Nordic XL vs 2018+ Compact P using the fan register hints in the menu

`config_flow.py`, `config_flow_menus.py` (new), `strings.json`, `translations/*`, `manifest.json`, `docs/faq.md`, changelog.
